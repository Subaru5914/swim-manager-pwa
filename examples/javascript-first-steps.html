JavaScript はじめの一歩

書く → 実行する → 結果を見る

最初は「1. 文字を表示する」だけで十分です。例の1行をそのまま入力し、次に文字を一つ変えてみましょう。

  1. 下の入力欄にコードを書きます。最初から入力例が入っています。
  2. 「実行する」を押すと、右側（スマホは下側）に結果が出ます。
  3. 文字や数字を一つ変え、もう一度実行します。

入力するのはJavaScriptだけです。<script> は不要です。記号・英字は半角にし、最初はPCのChromeまたはEdgeで使ってください。このファイルはダウンロードして開けば、通信せずに練習できます。

全部を消して書き直しても構いません。「入力例に戻す」で戻せます。

Ctrl＋Enter（Macは⌘＋Enter）でも実行できます。毎回、新しい状態で最初の行から実行します。
