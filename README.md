# 大学競泳監督シミュレーション PWA v1.21

iPhone横画面の各画面を、文字サイズを維持したまま横方向に凝縮しました。

- ホーム: 3枚の指標カードの間隔を縮小、下段2カードを横2列化
- 練習指示: 名前 / 学年 / 総合 / 専門の列幅を縮小、選手リスト自体も細く
- 選手一覧: 名前と学年の間を縮小、全列の左右paddingを縮小
- 全選手ランキング: 全列の間隔と列幅を再配分
- ゲーム内歴代記録 / 大会履歴 / 進路アーカイブ: 列間を縮小
- スカウト: 全列を画面幅内に再配分
- 施設: カード間隔・内部余白を縮小して4列表示
- 大会日程 / 参加標準 / 自チーム10傑: 専用コンパクト表に変更
- 文字サイズはv1.20から縮小していません
- 横画面専用・日本記録バランス調整は維持
