# 大学競泳監督シミュレーション PWA v1.17

iPhoneのSafariからホーム画面に追加して遊べるPWA版です。

- オフライン起動対応
- Service Worker対応
- オートセーブ
- セーブ書出 / 読込
- 参加標準突破時に標準タイム表示

GitHub Pagesで公開したURLをSafariで開き、共有 → ホーム画面に追加してください。
