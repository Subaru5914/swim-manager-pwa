# 大学競泳監督シミュレーション PWA v1.20

iPhone横画面の横幅を、文字サイズをこれ以上小さくせず再調整しました。

- 文字サイズはv1.19のまま維持
- 左右余白をさらに削減
- 選手一覧、ランキング、練習表、大会エントリー表の固定min-widthを撤廃
- 主要テーブルを width:100% + table-layout:fixed に変更
- 長いセルは折り返してページ全体の横幅を押し広げないよう変更
- 選手一覧の操作ボタンを2列グリッド化
- 能力チップは縮小せず折り返しで収める
- 選手詳細2列表示は維持しつつ内部余白をさらに削減
- 横画面専用・日本記録バランス調整は維持
