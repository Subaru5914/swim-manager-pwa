# 大学競泳監督シミュレーション PWA v1.57

HTML / JavaScriptだけで動作する大学競泳部の育成シミュレーションです。

## v1.57 の変更

- エントリーの能力表示はスピード・スタミナの2行に変更し、ターン表示を削除しました。選手欄のスタート・メンタルと、能力ランク・数値の表示は継続します。
- 中高生の学年は「中1」「高3」の形で表示し、大学生と同じ1年＝青、2年＝緑、3年＝橙のバッジで統一します。スカウトでは学年を高校名の欄から選手名の横に移し、全選手ランキングやレース・結果、歴代記録でも「年」を付けない同じ表記を使います。

## v1.56 の変更

- 大会エントリーの「能力表示」を、スピード・スタミナ・ターンの3行に整理。項目名、S〜Gの色付きランク、右揃えの数値を表示し、選手名の欄には共通能力のスタート・メンタルを表示します。個人メドレーはレース計算と同じ4泳法のバランスを反映します。
- 能力表示の種目列は読める幅を確保し、表の中を横スクロールできます。選手名と学年は左に固定され、PB表示との切替や参加標準の確認後もエントリーを保持します。選択済みの種目は青枠で強調します。
- 学年は1年＝青、2年＝緑、3年＝橙、4年＝紫の共通バッジに統一。エントリー、選手一覧、練習指示・結果、全選手ランキング、大会種目一覧、レース・結果、代表発表、10傑に適用します。歴代記録は記録時の学年、代表の保存メンバーは選考時の学年を表示します。

既存セーブを引き続き読めます。自チームの獲得済み能力・PB・大会履歴・卒業生の能力は維持します。旧バージョンで生成済みの一般CPU選手の能力・初期PBは、最初の読込時に一度だけ新しい基準へ調整します。CPUの肩書に残る実大会記録は保持します。

更新済みの公開URLへオンラインでアクセスし、ゲームを閉じて開き直してください。v1.57のService Workerが準備できると旧キャッシュは削除され、更新版もオフラインで遊べます。PC・iPhoneの自動同期には[Firebaseの設定](./CLOUD_SYNC_SETUP.md)と同じアカウントでのログインを行ってください。

## 開発と検証

ビルドやアプリ用パッケージのインストールは不要です。リポジトリのルートでHTTPサーバーを起動してください。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

数値・ルール・レース計算・セーブ移行のテストはNode.jsだけで実行できます。

```bash
node --test tests/balance.test.cjs tests/meets.test.cjs tests/cloud.test.cjs tests/saves.test.cjs tests/scouting.test.cjs tests/season.test.cjs tests/records.test.cjs tests/sprints.test.cjs
```

表示間隔・右揃え・1項目限定の練習・参加標準の判定、国内大会・世界大会・代表選考の画面操作、旧PWAキャッシュからの更新・オフライン再起動のテストは、PlaywrightとChromiumが利用可能な開発環境で実行します。クラウド環境には両方が導入済みです。

```bash
node --test tests/browser.test.cjs
```

Chromiumの場所は `CHROMIUM_PATH` で指定できます（既定値 `/usr/bin/chromium`）。実機iPhone / Safariでの最終確認は別途必要です。
